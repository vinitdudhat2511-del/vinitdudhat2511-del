# Loan Defaulter — Credit Risk ML Pipeline

End-to-end machine learning pipeline for predicting loan default risk from structured credit data.

Status: Draft

Overview
- Baseline models: Logistic Regression, Decision Tree
- Champion: XGBoost tuned with Optuna and RandomizedSearchCV
- Experiment tracking: MLflow
- Artifact formats: joblib model files, input schema

Getting started
1. Clone the repo
2. Navigate to this project folder
3. See notebooks/ and src/ for code (add these as you commit them)
